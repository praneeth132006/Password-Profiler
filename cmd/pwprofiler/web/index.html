02 / PASSWORD POLICY

Set the boundaries

Every exported candidate must match these requirements.

Required characters
Unique candidates, capped at your limit. Case variations, leetspeak and common suffixes are included.
Generation coverage
0 uses 3 positions; -1 includes every position in full mode.
Combines words using no separator, dot, underscore, and hyphen. Browser downloads are limited to 100,000 candidates and 60 seconds. Export an exhaustive configuration to complete the defined search in the CLI.
pwprofiler generate -c audit.yaml -o passwords.txt
Exhaustive runs remove count, work and intermediate byte caps and use exact deduplication. Time, RAM and disk requirements can be very large. Depth, selected transforms and policy still define the finite search.
Advanced policy
0 disables either limit. Repeats count consecutive identical characters.
Blocklist matches are case-sensitive and compare the whole password. Policy compliance does not measure password strength.
Inputs are processed locally and are not saved by the server.
